Build web and native apps using HTML + CSS.

Applications can be compiled into a single cga file and run on the web or on the local system via [ClickGo Native](https://github.com/maiyun/clickgo-native). You can build applications such as image editors, database management tools and file browsers, as well as admin panels.

## Installation

First, set the loading path for the ClickGo module, then import your entry file.

**index.html**

```html
<script type="importmap">
{
    "imports": {
        "clickgo": "https://cdn.jsdelivr.net/npm/clickgo@x.x.x/dist/index.js"
    }
}
</script>
<script type="module" src="index.js"></script>
```

It can also carry parameters and global variables.

```html
<script>
clickgo = {
    'config': {
        'cdn': 'https://cdn.jsdelivr.net',
    },
    'global': {},
};
</script>
```

## Usage

Use the [ClickGo Compiler](https://github.com/maiyun/clickgo-compiler) to compile the app folder into a cga file, then compile the entry file and reference it in the browser.

For splitting Forms in large applications, see [Local application components and Dock](./doc/sc/local-component.md).

Applications can use [shared commands](./doc/sc/commands.md) to connect buttons, menus, shortcuts, command palettes and AI interfaces to the same business execution logic. For the complete command registration, HTTP MCP, stdio and CLI integration workflow for desktop applications, see the [ClickGo Native Simplified Chinese documentation](https://github.com/maiyun/clickgo-native/blob/master/doc/README.sc.md).

**index.html**

```html
<script type="module" src="index.pack.js"></script>
```

**index.js**

```typescript
import * as clickgo from 'clickgo';
class Boot extends clickgo.AbstractBoot {
    public async main(): Promise<void> {
        await clickgo.task.run(this._sysId, 'xxx.cga');
    }
}
clickgo.launcher(new Boot());
```

### NPM

In a TypeScript environment, installing via NPM provides code completion.

```sh
$ npm i clickgo --save-dev
$ npm i jszip --save-dev
$ npm i vue --save-dev
```

## Notes

ClickGo automatically loads the Vue and jszip libraries, so **do not** include their JS or CSS files.
